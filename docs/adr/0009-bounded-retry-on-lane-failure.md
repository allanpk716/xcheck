# 泳道失败改有界重试:单元梯 60s×2 封顶15min/night_retry_max,先还原再重派、占位不回填、错峰 i×30s、轨迹落盘断链重建;耗尽 paused、终局 waiting

2026-09-19 十并行子代理打同一上游账号触发 429 集体阵亡:CLI 自带的秒级内部重试被持续拥塞打穿,不能当唯一防线;且多项目共用该账号,分钟级并发争抢是常态而非偶发。现行契约落者超时/失败立即记 paused(ADR 0007),恢复靠次日人工续跑——一次分钟级争抢就丢一整晚产能。决定(2026-09-20,spec 两轮评审收敛+D13 确认):实施段派发单元失败改**单元级有界重试**:

1. **先还原再等待**:失败检出(异常终止/回报缺失/超时;四态回报不触发,NEEDS_CONTEXT 走既有补材料)→可归票校验→三步还原(reset→checkout BASE→clean -fd,含越界残留)→才进等待梯;还原不可归票/失败不进梯,走既有"暂停清理记 waiting"。
2. **递增梯、单元独立**:60s 起跳、×2、封顶 15min,起跳/翻倍/封顶写死契约;每派发单元(实施位/票级评审位/终局评审)一条独立梯,N=`night_retry_max`(agents.toml [defaults],默认 5,0=关闭回落现行"失败即 paused");N=5 时额外等待合计恰 30min(1800s),另加 Σ各次尝试时长。
3. **占位不回填**:重试中单元占住实施位/评审位,等待期其他泳道照常、已落地票照常提交;就绪集路径互斥四态扩**五态**(+重试等待中,含已还原未重派,视同在跑)。
4. **同波错峰**:"同一波"=同一次调度循环内检出的失败集合,波内第 i 个(i 从 0 起)等待满后加 i×30s;续跑同一时点到期的等待单元按各自首行检出序号升序重赋 i。
5. **轨迹落盘、断链重建**:首行(impl/review/终局review 前缀+检出序号 m)在还原完成后落盘,m=本夜第 m 个失败检出、全阶段统一递增、终身排序键;此后每次**实际派发时**追记 `… retry k/N(<原因>)`,k≥1 沿用首行 m;断链续跑整档重等(按已耗 k 取下一档,不折算档内进度),计数从追记行重建、不重置。
6. **耗尽终局**:实施/票级评审耗尽记 `paused(重试耗尽:N×失败,末次原因,阶段=impl|review)`,终局评审耗尽走既有终局阻断 `waiting(终局评审重试耗尽,…)`、finish 不勾;**不新增台账状态**,票落定且实施侧重试过在票行尾注 `retries=k`(只记实施位)。
7. **明确不做**:全局重试预算、独立全局冷却、自动升降 lanes、帽外段(冒烟/评审 fan-out/run-agent.sh)重试、退出码白名单(二版,依赖 429 形态探针)。

**取代声明**:经用户确认(D1/D13),本决策**取代 ADR 0007 中『落者超时/失败记 paused,不拖队』条款(仅该条款)**;ADR 0007 的并发帽与调度决策不受影响。与 ADR 0007/0008 的边界:两者否决的是**配置层自动升降 lanes**(限流面前集体翻车,固定值、人工设),有界重试是**运行时对异常的有界响应**——不改 lanes 配置值、不自动升降并发,重试耗尽照样 paused,两者并行不悖。

## Considered Options

- **维持失败即 paused(现行)**——分钟级争抢是常态,一次即丢一整晚产能、恢复全靠次日人工,成本最大,否。
- **固定短间隔(1min×10)**——争抢窗口时长不可预知,固定 10 次×1min 长拥塞下照样打穿、短拥塞后干等;递增梯才对得准拥塞时长,否。
- **全局预算+独立冷却**——用户否决史:多项目争抢是**时间性**(别人占满某几分钟)非次数性,按次数设全局预算对不准;冷却让未撞限的泳道陪停,再添一套账,否。
- **本案:单元级有界重试**——恢复粒度=失败单元,梯对准分钟级争抢,与并发帽/调度决策边界清楚,采纳。

## Consequences

- 就绪集互斥四态扩五态(+重试等待中,含已还原未重派,视同在跑):重试中的票继续占径,新票派发自然减速,不会两票同改一批文件。
- 断链续跑整档重等:等待进度不跨崩溃折算,按已耗 k 取下一档;计数从追记行重建、不重置,审计不漂移。
- 检出序号 m 是排序键:仅随首行落盘、终身不变,续跑错峰重赋(i 从 0 起)与审计均按它排序。
- 已知残余窗口:链崩在"失败发生→还原完成落盘"之间(含还原时长,通常秒级)该次失败未入账,每次此类崩溃至多多一次尝试,有界性不破——口径以 D12 修订为准(F8 标注)。
- 帽外段(冒烟/评审 fan-out/run-agent.sh)仍零重试,等实证再议。
- 退出码白名单精准判 429 留二版,依赖 429 形态探针(独立后续任务);现行触发=异常终止/回报缺失/超时,四态回报不触发。
