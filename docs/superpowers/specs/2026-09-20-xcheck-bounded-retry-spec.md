# xcheck 夜链有界重试机制 Spec(2026-09-20)

- 来源:object = `.xcheck/20260920-091148/proposal.md`(night rev1)+ 同环 decisions.md(D1–D13)+ FINDINGS.md(9 条全解除)
- 决策记录:ADR 0009(本 spec 落地时创建,显式取代 ADR 0007 失败处理条款)

## Problem Statement

夜链实施段(实施泳道、票级评审、终局全分支 review)的所有 LLM 调用打同一个上游服务商账号,该账号并发上限还会被操作者的其他并行项目争抢。现行契约里任何泳道失败/超时 → 该票立即 paused,恢复靠第二天人工续跑:一次分钟级并发争抢就会把整票产能丢一晚。CLI 自带的秒级内部重试已被实证(2026-09-19 十并行集体阵亡)会被持续拥塞打穿,不能作为唯一防线。

## Solution

夜链操作者在实施段获得**单元级有界重试**:派发单元失败后先还原工作区,再按递增等待梯(60s→2min→4min→8min→15min 封顶,每单元最多 `night_retry_max`=5 次重试)原票重派;重试中的单元占住泳道位、路径保持互斥;同波失败按检出顺序错峰重派;重试轨迹全部落盘,断链续跑可重建计数;耗尽才记 paused,终局评审耗尽记 waiting。不引入全局预算、独立冷却或自动升降并发。

## User Stories

1. 作为夜链操作者,我想让撞上游并发上限的派发单元自动退避重试,以便分钟级争抢不再丢一整晚。
2. 作为夜链操作者,我想让失败的票在进入重试等待前先按现行三步还原,以便重派总在干净基线开始、派单包与实树一致。
3. 作为夜链操作者,我想让重试等待中的票占住泳道位且路径视同在跑,以便派新票自然减速、不会两票改同一批文件。
4. 作为夜链操作者,我想让同波失败按检出顺序错峰重派(第 i 个加 i×30 秒),以便不再集体同步撞限流。
5. 作为夜链操作者,我想让重试轨迹(阶段前缀+检出序号)在还原完成后立即落盘、每次实际派发时递增,以便断链续跑能重建计数、按序错峰、审计不漂移。
6. 作为夜链操作者,我想让重试耗尽的票记 paused(带阶段与末次原因)、终局评审耗尽记 waiting 且 finish 不勾,以便晨报如实呈现、合并永远由人决定。
7. 作为夜链操作者,我想只用 `night_retry_max` 一个旋钮控制重试次数(0=关闭、失败即 paused 回落现行),以便按服务商情况调整而不碰梯子形状。
8. 作为 xcheck 维护者,我想让 ADR 0009 显式取代 ADR 0007 的"落者超时/失败记 paused,不拖队"条款(仅该条款),以便两份有效决策不并存矛盾行为。

## Implementation Decisions

- **覆盖范围**:仅实施段子代理(实施位、票级评审位、终局评审);冒烟/评审 fan-out/run-agent.sh 不动(等实证)。每派发单元一条独立梯,各自消耗 N。
- **触发**:异常终止/回报缺失/超时;四态回报(DONE/DONE_WITH_CONCERNS/NEEDS_CONTEXT/Blocked)不触发,NEEDS_CONTEXT 走既有补材料通道。
- **还原**:失败检出→可归票校验→三步还原(reset→checkout BASE→clean -fd 含越界残留)→才进等待;还原不可归票/失败→不进梯,走既有"暂停清理记 waiting"。
- **互斥**:就绪集路径互斥四态扩五态(+重试等待中含已还原未重派)。
- **梯子**:60s 起跳、×2、封顶 15min;N=night_retry_max(默认 5,agents.toml [defaults],0=关闭回落现行);起跳/翻倍/封顶写死契约。时间口径:额外等待合计恰 30 分钟(1800s)+ Σ各次尝试时长。
- **错峰**:"同一波"=同一次调度循环内检出的失败集合;波内第 i 个(i 从 0 起)等待满后加 i×30s。续跑:同一时点到期的等待单元按各自首行检出序号升序重赋 i(从 0 起)。
- **占位**:重试中单元占住实施位/评审位,不回填不排队;等待期其他泳道照常、已落地票照常提交。
- **账本**(不新增票状态):
  - 首行(还原完成后落):`票 NN impl retry 0/N(<原因>,已还原,检出序号=m)` / `票 NN review retry 0/N(<原因>,检出序号=m)` / `终局review retry 0/N(<原因>,检出序号=m)`;检出序号 m=本夜第 m 个失败检出,全阶段统一递增,仅随首行落盘,终身排序键。
  - 此后每次重试**实际派发时**追记 `… retry k/N(<原因>)`(D13/F9);k≥1 行沿用本单元首行 m。
  - 断链重建:整档重等(按已耗 k 取下一档整档重等,不折算档内进度);计数从追记行重建不重置。
  - 票落定且实施侧重试过:票行尾注 `retries=k`(只记实施位);耗尽:`paused(重试耗尽:N×失败,末次原因,阶段=<impl|review>)`。
  - 终局评审耗尽:既有终局阻断语义 `waiting(终局评审重试耗尽,…)`,finish 不勾。
- **明确不做**:全局重试预算、独立全局冷却、自动升降 lanes、帽外段重试、退出码白名单(二版,依赖 429 探针)。
- **ADR 治理**:ADR 0009 记录本决策并显式取代 ADR 0007"落者超时/失败记 paused,不拖队"条款(仅该条款,经 D1/D13 用户确认);ADR 0007 文首加修订指针。落地文档同步标注 D11 残余窗口口径已由 D12 修订(F8)。

## Testing Decisions

- 只测外部契约行为(盘上 Markdown 契约 + 配置 + 静态布线断言),不测实现细节。
- `xcheck/tests/night-parallel.test.sh` 追加断言(沿用 contains/absent 静态检查先例):还原次序(失败检出→还原→等待)、互斥五态、占位不回填、错峰两情形(正常波定义+i 从 0;续跑按首行检出序号升序重赋 i)、三种首行记法均含阶段前缀与检出序号、k≥1 沿用 m、追记行实际派发时落盘、整档重等、续跑重建计数不重置、retries=k 只记实施位、耗尽 paused 带阶段、终局耗尽 waiting/finish 不勾、时间口径恰 30 分钟(1800s)、四态不触发、不新增台账状态、`night_retry_max` 旋钮与 0=关闭语义。
- 契约测试不跑真实时钟;未来语义回放测试用模拟时钟/事件注入。

## Out of Scope

主会话自身上游失败(CLI 内部行为,链崩走既有恢复);冒烟与评审 fan-out 段重试;主动降并发;退出码白名单判据;429 形态探针(独立后续任务)。
