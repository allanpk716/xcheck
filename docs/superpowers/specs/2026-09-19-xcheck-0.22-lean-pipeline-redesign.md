# xcheck 0.22 精简管道重构设计（lean pipeline redesign）

日期：2026-09-19 · 状态：访谈共识已确认（grill-with-docs），未实施。
基线：`origin/feat/review-convergence`（v0.21.0-rc.1, 1c067e8）。目标版本 **0.22.0**，分支 `feat/lean-pipeline` 自基线切出；0.21 线不再出 rc.2。
开发方式：**不强制并行**，单一上下文顺序实施亦可；A 与 B/C 文件集不相交，允许机会性双泳道。

## 北极星

> 多 agent 审核 → 验证 → 论证收敛 → 自动 spec → DAG 票 → **并行实施** → 推分支 → 晨报一键开 PR 链接。

一切为挂机效率服务；护栏跟着事故走，不跟着想象走。

## 23 条发现的归宿

- 机械层 M1（hook 穿透）→ 批次 A `--no-verify`；M3（凭据挂死）→ 批次 A prompt-off；M2（`GIT_CONFIG_*` 注入）→ ADR 0004 出范围（TM-3）；M4/M5（gh limit/GHES 端口）→ 随 `night-pr.sh` 删除而消失。
- 兼容下限（git≥2.36 / bash≥4.3）与测试小洞（mapfile、尾部换行）→ 批次 E 记录/修复。
- 文档回归 14 条 → 批次 B（格式/字段类，字段字典一次解决）与批次 C（行为类）。

## 不变式清单（批次 B 改写的约束、批次 C 回填的底账、验收时逐条核对）

1. 原分支零 commit / push / pull / rebase；夜链只在自己起的分支上提交
2. 推送只推夜链分支 ref，显式 refspec，绝不 force，不交互（prompt-off），不跑本地 hook（--no-verify）
3. **每票提交后即推夜链分支**（防全损，ADR 0003 的事故教训）；推送失败降级记账不挂链
4. 实施结果与发布状态分开记账；全绿 ≠ 已发布
5. 复审环评审面板 = 旧环 selected ∩ 当前已安装（钉死）
6. 终局全分支 review 派最强档
7. 修订稿正文自代入纪律（中性陈述，不点名 agent）
8. 查证只读判据直指的文件，不展开探索；查无实据 = 未确定
9. 事实核实与阻断裁定分离；属实 ≠ 必改；活动约束定义不变
10. F 编号跨轮稳定；重开须新证据；规则单一权威句
11. diag 永不实施（单一权威句）
12. --auto-review 不通知、不推送、不开 PR、不建 NIGHT
13. 无 git / 无 HEAD → 只审核不实施
14. 无人值守自动修订 ≤ 1 次；无进展定义不变
15. 停点：未决逐个问，泛答 ≠ 全部授权（铁律 3 与此对齐）
16. 并行：编辑并行提交串行；路径不相交才并行；落者不拖队
17. 背景附带须声明"未经逐条确认，若有出入请打断"
18. 票 complete = 分支上可达提交 + scoped 验证证据
19. 晨报自包含（不翻本机文件就能懂要决定什么）
