# xcheck 0.22 精简管道重构设计 · 修订版 rev1

> 本文件是 `2026-09-19-xcheck-0.22-lean-pipeline-redesign.md`(+plan+4 ADR 六件套)的修订版,整合首轮评审查实的 16 条问题与 3 条存疑的处置。原稿不动;收敛后按本版批量改正式文件。修订对照:①发布链路(#1-#5) ②脏区与提交安全(#6,#7,#8,#11) ③并行失败与恢复(#9,#12,#15) ④流程纪律(#10,#14) ⑤口径与门禁(#13,#16) ⑥存疑处置(调度状态机/回调/崩溃清理)。

## 北极星(不变)

多 agent 审核 → 验证 → 论证收敛 → 自动 spec → DAG 票 → 并行实施 → 推分支 → 晨报一键开 PR 链接。护栏跟着事故走。

## 发布链路修订(替代原批次 A 的旗标设计)

**publish 认证行为(修正 #1/#2)**:
- 保留 `GIT_TERMINAL_PROMPT=0`(阻断 TTY 交互提示)。
- **不清空 credential.helper**——GCM 等凭据助手是 HTTPS 主路径的合法认证手段,清空会把整晚推送全部打成失败。防 GUI 弹窗改用 `GCM_INTERACTIVE=never`(已设则尊重原值):GCM 无缓存凭据时返回错误而非弹窗。
- SSH 形态 remote(`git@`/`ssh://`):该次推送置 `-c core.sshCommand="ssh -o BatchMode=yes"`,host key 未确认/passphrase/agent 缺失一律快速失败;语义 = 无人值守要求非交互密钥已就绪,未就绪属环境事实,记账未推。
- **start 时认证预检**:夜链开始(而非首次推送时)`git ls-remote <remote_url> <pr_base>` 探测一次;失败 → 本夜记"未推(认证/远端不可达,预检失败)",不再每次推送都撞墙。推送失败降级不挂链(沿 ADR-0003)。
- publish 与按票 commit **均带 `--no-verify`**(修正 #11):TM-1 防挂死覆盖 commit+push 两条路径。

**compare 链接转换规则(修正 #3/#4)**:晨报链接前先做 remote→web 归一:`git@host:o/r.git`→`https://host/o/r`;`ssh://git@host:port/o/r.git`→`https://host:port/o/r`;`https://host/prefix/o/r.git` 保留子路径;再拼 `/compare/<pr_base>...<branch>`。归一失败(识别不了的形态)→ 晨报印 remote 原串+分支名,不印死链。

**start 恢复语义(修正 #5)**:`start` 在分支已存在时——当前 HEAD 即夜链分支 → 幂等通过;不在 → 尝试 `git switch <夜链分支>`,git 因未提交改动冲突拒绝 → 记 waiting"操作者改动阻挡分支切换",实施暂停只留审核账,切换成功 → 继续。**start 落 dirty baseline**:`git status --porcelain` 全量存 NIGHT(修正 #6 的前提)。

## 脏区与提交安全(修正 #6/#7/#8)

- **脏区重叠票停靠**:调度就绪条件加一条——票涉及路径与 dirty baseline 相交 → 该票 `paused(与操作者未提交改动重叠,防捎带/防冲突)`,其余票照跑。夜链启动播报"你的 N 个未提交文件与 M 张票重叠,已停靠"。
- **运行时路径校验**:每票 commit 前,`git status --porcelain` 中该票产生的改动文件集必须 ⊆ 其标注路径;超出部分不 add、留工作区、记入 NIGHT 越界清单(终审与晨报呈现)。D6 加对应测试:越界改动不被捎带提交。
- **不变式 18 改写**:票 complete = 分支上可达提交 + scoped 验证证据,**且该票路径与脏区不相交**(由停靠规则保证,使"分支单独可复现验证"成立)。ADR-0005 Consequences 相应改口:接管模式的语义变化 = 新增脏区重叠停靠规则,不再声称"语义不变"。

## 并行失败与恢复(修正 #9/#12/#15)

- **失败票路径清理**:泳道失败/超时记 paused 时,`git checkout <该票BASE> -- <该票标注路径>` 清掉半成品(BASE = 派发时 HEAD,账本记完整 OID);路径与脏区不相交保证不误伤操作者改动。账本无 complete 提交但路径有残留改动的票,恢复时同法清理后再重算就绪集。崩溃后手动收拾:按 NIGHT 票路径清单逐票 checkout(存疑#9 的处置)。
- **票状态机显式化(存疑#5 的处置)**:`running → committed → reviewed` ;`reviewed` = complete;评审发现 Critical/Important → `rework`:**追加**修复 commit(已推送旧提交不 revert 不 force,历史带修复),scoped re-review 上限 2 轮,超限 → paused(带评审发现)。已提交≠已验收,两字段分开记账。
- **副作用约束(修正 #15)**:票标注增"副作用声明"(测试/构建产物目录、端口、需独占的验证命令);声明独占验证的票,其验证段**串行**执行;未声明的局部验证限类型检查/单文件测试级。

## 流程纪律(修正 #10/#14)

- **不变式自检覆盖全部改写批次**:B/C/D(及 A 若动 flow)每次改写逐条自检;M2 判据加"不变式核对表复核 D 批次"。
- 不变式清单增补至 25 条(新增:脏区重叠票停靠、失败票路径 revert、commit --no-verify、rework 追加提交不 revert、外部材料失败关闭)。
- **新增任务 B7**:入口简化落点——壳删三选一入口问,改 `--auto-review` / `--night` 旗标直选,无旗标 = 交互评审,与 run-mode 三组合对齐。

## 口径与门禁(修正 #13/#16)

- **live 对比口径归一**:每票均摊墙钟(总墙钟/完成票数)、LLM 时间占比、并行度分布三项;基线 = ferryman 的 38 轮/票与 96.5% 单代理占比;目标:每票均摊墙钟较基线降 ≥40%(2 泳道理论减半留余量),不达不tag。
- **沙箱触发可执行化**:摄入记录 `material = trusted(本仓文件/用户手输) | external(贴文/URL/跨仓材料)`;`external + TARGET=implementation` → **失败关闭**:不进实施,记账"外部材料+自动实施需先上沙箱"。一个字段一个门,不猜。

## 回调机制(存疑#9 处置)

E1 改写:搬运工"回合内阻塞等待"纪律不动(它就是防"停回合等通知"事故的),只把 `for i in seq` 轮询替换为 TaskOutput 阻塞调用;不存在回合后回调依赖。主会话侧收集 = task-notification 唤醒(harness 已验证机制)。

## 其余不变

五批次结构、ADR-0004/0005/0006/0007 的取舍与 Considered Options、live 四指标其余三项、与 ADR-0003 的关系(每票即推保留)——均维持原稿;上述修订为增量。
