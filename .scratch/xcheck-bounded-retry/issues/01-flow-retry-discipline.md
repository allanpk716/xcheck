# 票 01 · flow.md 实施段有界重试纪律(核心契约)

## What to build
在 `xcheck/lib/flow.md` 第 11.6 步(并行实施)中,把现行"泳道 agent 落者超时/失败记 paused 不拖队"替换为**单元级有界重试纪律**,覆盖实施位、票级评审位、终局全分支 review 三类派发单元(均为主会话子代理)。内容要素(全部已定案,见 spec 与 decisions D1–D13,不得增删语义):
1. **触发**:派发单元异常终止/回报缺失/超时;四态回报(DONE/DONE_WITH_CONCERNS/NEEDS_CONTEXT/Blocked)不触发。
2. **重派基线**:失败检出→可归票校验→立即现行三步还原(reset→checkout <BASE>→clean -fd 含越界残留)→还原完成才进等待;还原不可归票/失败→不进梯,走既有"暂停清理记 waiting"路径。票级评审/终局 review 只读不涉还原。
3. **等待期互斥**:就绪集路径互斥由四态(在跑/paused未清理/committed-unreviewed/rework)扩为**五态**(+重试等待中含已还原未重派,视同在跑)。
4. **重试梯**:60s→2min→4min→8min→15min(封顶),每派发单元独立计,最多 `night_retry_max` 次(agents.toml [defaults],0=关闭、失败即 paused 回落现行);起跳/翻倍/封顶写死;时间口径:额外等待合计恰 30 分钟(1800s)+ Σ各次尝试时长。
5. **错峰**:"同一波"=同一次调度循环内检出的失败集合;波内第 i 个(i 从 0 起)等待满后加 i×30s;**续跑**:同一时点到期的等待单元按各自首行检出序号升序重赋 i(从 0 起)。
6. **占位**:重试中单元占住自己的实施位/评审位,不回填、不进就绪集排队;等待期其他泳道照常、已落地票照常提交。
7. **账本**(不新增票状态,写入 NIGHT):
   - 首行(还原完成后落):`票 NN impl retry 0/N(<原因>,已还原,检出序号=m)` / `票 NN review retry 0/N(<原因>,检出序号=m)` / `终局review retry 0/N(<原因>,检出序号=m)`;检出序号 m=本夜第 m 个失败检出,全阶段统一递增,仅随首行落盘,终身排序键。
   - 此后每次重试**实际派发时**追记 `… retry k/N(<原因>)`;k≥1 行沿用本单元首行 m。
   - 断链重建:整档重等(按已耗 k 取下一档整档重等,不折算档内进度);计数从追记行重建不重置。
   - 票落定且实施侧重试过(k>0):票行尾注 `retries=k`(**只记实施位**);耗尽:`paused(重试耗尽:N×失败,末次原因,阶段=<impl|review>)`。
   - 终局评审耗尽:既有终局阻断语义 `waiting(终局评审重试耗尽,…)`,finish 不勾。
8. **明确不做**:全局重试预算、独立全局冷却、自动升降 lanes、帽外段(冒烟/评审 fan-out)重试。
9. **已知取舍**(如实入文):链崩在"失败发生→还原完成落盘"之间该次失败未入账,每次此类崩溃至多多一次尝试,有界性不破。
10. **恢复语义同步**:flow.md 的 NIGHT 恢复语义段与"边界与异常"表中涉及泳道失败的行,与上述纪律对齐(如"账本无 complete 提交但路径有残留的票先清理"保持不变)。
同时更新 PROGRESS/NIGHT 无关;**不改动** SKILL.md、subagent-carrier.md、其他 lib 文件。
